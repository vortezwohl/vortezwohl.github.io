[2019-04-28|SporaticPinecone|10] I use inkscape for scientific figures. Free, easy to use, makes nice figures. Scalable vector graphics so you can have as much resolution as you desire. Get the tex text add on to easily insert latex equations. For plots I use pgfplots in latex.
[2019-04-28|atrlrgn_|4] It's weird that nobody mentioned paraview. It's free and open source and one of the best post-processing tools (the best if you ask me). For basic shapes, powerpoint is really nice. It's a pity that its libre office counterpart isn't that good. For plots, contours. Paraview is still good, but I prefer matlab or python matplotlib. Also, I know many people uses tecplot or gnuplot. I've never used them, so I don't know much.
