### 1.2 API/批量
- Sonauto Scale $330/月（660k credits，~$0.06/首）；MiniMax ~$0.15/首（**已停止对新用户开放付费 API**）；Stable Audio ~$0.20/首；Mureka platform.mureka.ai 按请求计费。
- 【推断】API 收缩潮（MiniMax 关门）意味着"依赖单一商用 API"的产品有供应链风险——本地开源渲染（ACE-Step）或多家 API 抽象层是稳妥架构。

### 1.3 结构性教训（塌方两案）
- 订阅制+云端锁定+版权危机 = 火药桶: Udio 禁下载、Suno 移除旧模型+下载配额，都触发退订潮。
- **下载配额是"假所有权"的显性化**: 用户创作量与可下载量差 40-100 倍，本质是逼用户留在云端消费。【推断】
- 信任修复成本极高: 即使 Suno 官方 AMA 全程亲切（2025-09），半年后照样崩——**条款与产品架构问题不能靠社区运营弥补**。

## 3. 本 idea 的合规地图【推断+事实组合】

### 3.1 三层许可矩阵
| 层 | 组件 | 许可 | 商业风险 |
|---|---|---|---|
| 交互/引擎 | Strudel（AGPL）或 Rustel（AGPL） | AGPL-3.0 | 若产品含并分发此引擎→须开源整个产品（含服务端交互逻辑，AGPL 网络条款）；闭源路线需自研引擎或商用授权谈判 |
| 渲染 | ACE-Step（Apache 2.0 含权重） | Apache | 商用最干净；质量依赖社区迭代 |
| 渲染 | YuE2 权重 | CC BY-NC 4.0 | 个人用户可商用其生成物；**公司**商用需联系授权——对"工具平台"形态不利，对"个人工具分发"形态微妙 |
| 训练数据 | agent 生成 pattern + 开源模型渲染 | — | 不涉及"训练于侵权数据"的原罪（模型许可随组件）；生成物版权归属因司法辖区而异（美国: 纯 AI 生成无版权；有人类创作贡献可主张） |

### 3.2 Strudel 政策的边界（再次强调）
- 用户个人用 LLM 生成 pattern = 政策允许（明文）；
- "fork/import 进 corporate AI platforms" = 官方强烈劝阻；
- **安全姿态**: 产品定位为"Strudel 生态的外部副驾"（用户自备引擎，产品不捆绑不修改引擎），并公开声明尊重 POLICY.md——既合规又不树敌。【推断】

### 3.3 生成物版权
- 美国: 纯 AI 生成内容无版权（Human Authorship 要求）；有 pattern 代码+人工修改记录的产出可主张人类贡献部分——**"代码即创作记录"恰好是 Strudel-agent 的天然合规资产**（每次 agent 交互都有代码 diff 佐证人类创作链）。
- 平台分发: Bandcamp（"resistance"，反 AI 立场）vs Spotify/YouTube（AI 混杂）——发行出口需在产品内做 provenance 标注/导出选项。【事实+推断】

### 3.4 风险清单
1. 开源模型权重许可变更风险（ACE-Step/YuE2 均可能改条款）；
2. AGPL 传染: 若为图省事直接 bundle Strudel 而产品闭源=违约风险；
3. "AI slop"舆情风险: 产品若被社区定性为 slop 工厂，将复制 Stave 审查战；
4. 跨境合规（中国用户使用境外模型/API）与支付通道；
5. 生物特征类功能（若做声音克隆）避开 Suno 式"永久不可撤销"条款设计。

## 4. 变现设计参照系【推断，锚定已验证价格带】
- 入门 $8-14/月已被全行业验证；买断制（SynthV $99/ACE $398+）在"工具心智"人群中被验证且**无订阅变脸怨气**；
- 版权分层（免费生成版权归平台/Pro 归用户）是 B2B 细分已验证的转化引擎（AIVA/SOUNDRAW 先例，14 号报告存量）；
- 对本产品: "本地资产+买断或低价订阅+按量渲染费"的组合最贴合"所有权叙事"；免费层可无限玩（引擎本地免费），渲染/云同步/高级 agent 能力收费。
