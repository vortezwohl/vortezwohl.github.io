# 研究线B · 生成式音乐 SaaS 全景定价快照 (2026-11, WebSearch 综合)

## 头部(整曲生成)
- Suno: Pro $10(下载20首/月), Premier $30(下载60首/月, 含 Suno Studio 2.0)
- Udio: 已死(2025-10 UMG 和解→下载锁死→老服务关停, 2026 以 UMG 授权平台重启)
- Riffusion→ProducerAI: **2026-02 被 Google 收购**(PitchBook 列名 "Google Flow Music"); 三方统计 App 收入 ~$123.5K/月(2026 末)
- Eleven Music (ElevenLabs): 信用点制, 音乐包含在各档($1 首月 starter 起, 10k credits/月@starter); 卖点=voice+music 一体
- Stable Audio 2.5/3.0: 免费50credits/月; Solo $12→Studio $199/月; API≈$0.20/首; 主打"授权训练数据干净/可自托管"

## 价格带腰部
- Sonauto: Starter $11/月(≈200首) / Pro $88 / Scale $330——单曲成本最低(~$0.06/首)
- Boomy: 免费层最宽松(无限创建/保存, 个人下载); 付费 $3-14/月解锁商用
- Mureka(昆仑万维): $8-30/月档; API 经 platform.mureka.ai + useapi.net 等网关
- MiniMax Music: API ~$0.15/首; M Plan 订阅 $264-1560/年; ⚠️ 2026-08-20 起付费音乐 API 停止对新用户开放, 免费 endpoint 逐步下线(收缩/合规信号)
- SOUNDRAW: $11.04-32.50/月(B2B 背景音乐向)
- Beatoven.ai: $3-14/月(情绪配乐向)
- Mubert: Creator ~$11.69/月 + API/流媒体向

## 结构判断
- 入门付费带宽集中在 $6-14/月; 天花板 $199-330(B2B/API 向)
- 头部心智: Suno 独大, Udio 死, Riffusion 被收购——"独立生成式音乐 SaaS"作为品类正在被巨头吸收
- 竞争焦点已从"生成质量"转向: 版权洁净度(Stable Audio/授权模型)、成本(Sonauto)、生态(Suno Studio 插件平台、Eleven voice 一体化)
- 开源模型侧(YuE 2/ACE-Step/MiniMax 开源权重)承接退订用户——见 open-models 笔记
