# 研究线E · DAW 内置 agent 浪潮(2026 现状)

## Gopher (Image-Line 官方, FL Studio 内置 AI 助手)
- 来源: Motion Media / RouteNote / LiaPlugin 博客(WebSearch 综合, 2026)
- 起点: 基于 FL Studio 官方手册训练的专家 chatbot(排障/混音/声音设计/脚本问题)
- FL Studio 2026 升级为 agent 式控制:
  - 整理音轨、设置电平
  - Channel Rack → Mixer 路由/音频路由
  - 从打字指令生成 Piano Roll 脚本与 VFX 脚本
  - 一句话自动化重复性制作任务
- 社区反应(Larry Ohh 等 demo): "game changer", 但执行慢、只能控制部分功能; 有用户自建 AI 工具替代/扩展它
- 战略含义: 最主流入门 DAW 已官方内置 agent——"打字→DAW 执行"交互范式正在被默认化

## 相邻事实(同轮 WebSearch)
- Logic Pro: 内置 AI Session Players(AI 键盘手/鼓手/贝斯手, 输出 MIDI)
- Suno Studio 2.0: session-aware Chat Bar + prompt 自建插件(见 agent-01 笔记)
- MCP 生态: 用户已养成"app + MCP"搜索习惯; Ableton/Unreal 等社区桥接项目存在
- 通用 computer-use agent(如 GPT-6 Astra)直接操作 FL Studio 的演示已传播

## 空白点(初步, 详见 08 机会报告)
- 官方 agent 逐 DAW 割据(Gopher 只懂 FL, Logic AI 只在 Logic);
- 无跨 DAW 的"会话态制作助手"; 无代码资产化(personas/工程状态锁在单一软件);
- 生成式(音频后处理型)与 agent 式(操作工具型)两条路线并存, 后者检测不可行→规避 AI 检测/版权焦虑;
- live coding(Strudel)路线=第三个生态位: 跨平台/浏览器/免费引擎/代码即乐谱, 但该社区反 AI 营销敏感。
