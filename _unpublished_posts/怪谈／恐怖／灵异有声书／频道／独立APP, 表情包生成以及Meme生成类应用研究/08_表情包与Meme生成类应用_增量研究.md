## 2. 平台级事件：GIPHY 三度易主【事实】

Meta 2020 年约 **$4 亿**收购 → 英国 CMA 反垄断强制剥离 → **2023 年以 $5300 万卖给 Shutterstock**（亏损约 $2.6 亿）；Tenor GIF Keyboard 停更两年。
- 【修正】网传"Meta 2025 年把 GIPHY 卖给 PicsArt"查无实据，勿引用；
- 【推断】通用 GIF/贴纸**平台**的独立估值逻辑已被证伪——钱在"分发集成"（键盘/聊天集成）不在"独立 App"。**不要做平台，要做工具+渠道集成。**

**StickerAI 开发者一手证据**（[r/iosapps 全文](https://www.reddit.com/r/iosapps/comments/1fzp2dc/)）：
- 开发者："Apple review is the biggest hurdle… we were rejected twice for missing content moderation/reporting"——**苹果对 AI 类目强制要求内容审核+举报 UI，是上架前置成本**；
- 用户："the killer feature for me is the one-tap add to WhatsApp pack"——**一键导入贴纸包是杀手功能**（佐证已有研究"生成式+一键导入"断层论）；

【结论】2024–2026 没有出现 AI 贴纸爆款独立 App；流量入口在平台原生功能和 bot，不在商店搜索。

## 4. 中国微信表情生态：直接付费≈0，钱在 IP 授权【事实（本次新验证）】

### 4.1 官方规则（协议原文）
微信表情开放平台《赞赏功能使用协议》原文：赞赏所得="微信用户赠与金额-渠道技术服务成本"，且**腾讯有权单方调整成本比例**；付费表情平台技术服务费约 10%（高置信待核）。

### 4.2 一手收入账本（2025–2026）
创作者"数字游民9527"：2025-04 两天做 6 组表情上架，截至 2026-01 **累计发送约 36 万次，总收入仅 125 元**；打赏九成来自朋友。作者原话："如果奔着功利心来的，可以放弃了，投产太低。"
- 【事实】**发送量≠收入**；微信表情是"用的人多、付钱的人少"的生意。

### 4.3 IP 天花板：奶龙
人民日报 2026-01 报道：全网粉丝 **3800 万**、合作品牌 **200+**（腾讯/美团/伊利/比亚迪/周大福）、衍生品 **2000+ SKU**、销往 57 国、**带动全产业链产值过亿元**——模式是"内容+授权"双轮驱动，表情/短视频只是流量入口，钱在授权与周边。
- 历史对照组：乖巧宝宝（个人创作者天花板，两年下载 1.5 亿次、打赏约 50 万元）；萌力星球（19 亿下载后转 IP 授权）；十二栋文化（表情是流量入口，营收在 IP 开发）。

### 4.4 其他渠道【事实】
抖音表情开放平台（上传→审核→表情商城，创作者有现金流量权益）；百度/搜狗输入法开放平台是"品宣换曝光"不是卖表情分成；B站表情是会员特权体系无创作者分成。

## 5. Meme API / B2B：基础设施已商品化【事实】

- **Imgflip API**：免费层+Premium $9.99/月起（含 `caption_gif` $0.02/次、1M+ 模板搜索 $0.005/次、去水印 $0.01/次、**AI meme 端点** $0.02/次）——做 B 端 meme 服务时 Imgflip 是现成基础设施不是壁垒；
- Supermeme.ai：$19.99/月起（年付口径）含品牌套件+API+110+ 语言；上一份研究"$5k MRR"结论沿用，**但纯 meme B 端窗口在收窄**：竞争来自 Canva/Predis/Simplified 等通用工具的功能内嵌【推断】；
- 【推断】B 端差异化要靠"品牌一致性+批量多语言+分发"组合，不在生成本身。

## 6. 恐怖频道 × 表情包/Meme 的交叉机会【推断（有先例支撑）】

1. **恐怖 IP 贴纸商品化已被验证**：伊藤润二官方 LINE 贴纸 240 日元/组；Amazon/Etsy 万圣节恐怖贴纸 $5–13 在售；LINE 每年 10 月有万圣节贴纸档期——恐怖贴纸有天然季节性流量脉冲；
2. **频道先例**：SrPelo（Spooky Month）→官方周边贴纸；Morbid 播客→社区梗周边；Creepypasta 62 件贴纸包是标准品类——**"频道角色→自创贴纸包→粉丝群/季节性投放"路径成立**；
3. **规模参照**：r/creepy 62.7 万周访客；恐怖 meme 无独立大版块，渗透在所有大 meme 社区（r/cursedimages、r/TIHI 等）；
4. **边界（重要）**：贴纸是**频道的运营与品牌物料**，不是独立收入线——个人微信表情直接付费极弱（§4.2）；IP 授权是大头但前提是角色先成为 IP（奶龙路径，重内容运营）；**必须自创角色规避 IP 授权风险**（伊藤润二贴纸全部为官方发行）。
